# fuzzy finder

[fzf](https://github.com/junegunn/fzf) is a simple command-line fuzzy finder that is highly customizable in the way it behaves and looks.

## Installation

- macOS — `brew install fzf` using [Homebrew](https://formulae.brew.sh/formula/fzf)

## Custom Config

The [fzf-file-picker.zsh](./fzf-file-picker.zsh) is the function I have added to my `.zshrc` file on my macbook.
